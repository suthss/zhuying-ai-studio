## 主要功能

- OpenCV / CubiCasa5K本地识别，可选千问辅助结构理解与重建；用户确认尺度和房间用途。
- 四步需求问答，13类参数化家具，本地包含、避障与通路检查。
- 地板、墙面、门窗编辑，固定视点三维环视，JSON/GLB导出。
- 六类工序的照片与前后对照，人工确认、未知区间、计划提示与整改历史。
- SQLite多模型项目库、IndexedDB本地草稿、材料估算与业主周报。

## 真实验证及边界

2026-10-17工程回归：前端164/164通过；后端225项测试及299个子用例通过，0失败、错误或跳过；TypeScript与Vite构建通过，主包体积警告保留。工程测试的AI响应采用模拟，不当作云端视觉准确率。

2026-10-15的10张自绘控制图实际本地识别中，自动选择的房间平均IoU为0.847、房间F1为0.862。该小型控制集有2种基础拓扑，不构成真实户型总体准确率。家具干扰图仅识别3/6房间、IoU0.234，失败记录保留。此对照不包含AI重建。

室内与外立面影像为真实公开数据，模型、责任人、施工计划和整改事件为演练配置。没有真实用户反馈、企业试点、专利、软著或节约工时/收益证明；[反馈表为空白采集工具](%E7%BC%96%E5%8F%B7%E5%BE%85%E8%A1%A5-AI%2B%E5%9C%BA%E6%99%AF%E5%88%9B%E6%96%B0-%E7%AD%91%E6%98%A0%E6%99%BA%E8%83%BD%E5%BB%BA%E6%A8%A1%E4%B8%8E%E6%96%BD%E5%B7%A5%E7%AE%A1%E6%8E%A7%E5%B9%B3%E5%8F%B0-05%E7%9C%9F%E5%AE%9E%E7%94%A8%E6%88%B7%E5%8F%8D%E9%A6%88%E9%87%87%E9%9B%86%E8%A1%A8.md)，不是已取得的佐证。
